Suggestions appear after a dot or a short pause, filter as you type, and never block typing. Signature and docs sit beside the list.

Ctrl+R saves and runs the file in a fresh process. The header shows run number, time and exit code.

The error leads, then your line with Python's own markers. Library frames collapse. Ctrl+E puts the cursor on the failing line.

input() works: type in the output pane. A small spinner shows while it runs, and Ctrl+C stops it, including any child processes.

ruff checks while you pause. One dot in the margin; the message shows in the status bar when the cursor is on that line.

Rendered by Textual with the proposed theme, then framed as a Windows Terminal tab. Panes are separated by background shade, not lines. Blue is the only accent.

Decisions

Chosen for speed and reliability

PartPickWhy, with measured numbers
UITextualThe only option that can produce the screens above without hand-drawing. First paint 262–321 ms on the test VM; prompt_toolkit was about 200 ms but has no layout or theme system.
EditorTextual TextArea + small fixUndo, selection and highlighting built in. Stock version slows to 158 ms per key at 6,300 lines; highlighting only the visible lines brings it to 50 ms, and 21 ms at 1,000 lines.
SuggestionsJedi in its own processMature and pure Python. 3–54 ms once warm. In a thread it froze typing for up to 66 ms, so it gets its own process.
Lint, formatruff16–24 ms per call, so it can check while you pause, not only on save.
Running codeSeparate processYour script can't crash or freeze the editor. Python starts in 18–24 ms.
≤ 250 mslaunch to first screen (target; re-measured on your PC first)
≤ 25 mskey to screen, files up to 1,000 lines
≤ 100 mssuggestions after a dot, warm
~ 130 MBtotal memory with suggestions on (PyCharm: about 1.5 GB)
Windows

What changes because it's Windows

Windows Terminal is the targetFull colour and clipboard work there. The old console window gets a 256-colour version of the theme.
Finds your Python.venv\Scripts\python.exe next to the file, then the py launcher. Shown in the status bar.
Stop always worksCtrl+C sends a break to the script's process group, then ends the whole process tree after one second.
No special fontUses only plain symbols from Cascadia Mono, the Windows Terminal default. No Nerd Font.
Faster first launchBytecode compiled at install, so Defender doesn't scan fresh files on every first run.
Keys that Windows Terminal sendsCtrl+R, Ctrl+E, Ctrl+P, F5. Nothing that needs Ctrl+Shift or Ctrl+Enter.
